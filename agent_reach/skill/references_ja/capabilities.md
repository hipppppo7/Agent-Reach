# 能力の範囲

ユーザーが「何が取れるか、漏れなく取れるか」を尋ねたとき、または結果の網羅性を判断する必要があるときに読む。下の表は宣言された能力であり、すべてのネットワーク、アカウント、コンテンツで実地テスト済みという意味ではない。

## 3つの層

- **公開経路で試せる**：Agent が既に持つ Web ツール、ネイティブツール、公開 API でタスクを満たせる可能性がある。ブラウザのインストールやログインは不要。実際に取得できた証拠に基づいて回答する。
- **Reach が補う**：現行リリースが宣言している動作。`agent-reach channels` を参照。設定が必要なときは、まず専用ブラウザに保存済みのセッションを再利用し、選んだ経路が実際にログインを要求する場合に限りユーザー本人がログインする。
- **このマシンで検証済み**：このマシンで最近受け入れ確認に成功した具体的な動作だけを挙げる。インストール、セッションの保存、ネットワークの到達性は、いずれも機能の受け入れ確認と同じではない。

## このリリースのチャネル

| チャネル | 公開経路で試せること | Reach が補うことと限界 |
|---|---|---|
| GitHub | 公開リポジトリ、README、Issue/PR | リポジトリ検索、リポジトリ／Issue／PR の読み取りと返ってきたコメント。プライベートの権限は別途判断する |
| YouTube | 検索、タイトル、概要。ネイティブツールで一部のコメントと字幕本文が取れる場合がある | search/read/subtitle/transcribe。現時点で統一的な comments 動作はない。トラック一覧は字幕本文ではない。字幕がないときの文字起こしは対応するツール次第 |
| Bilibili（B站） | 検索、概要。一部の公開 API はコメントと親子 ID を返す | search/read/hot/subtitle。現時点で統一的な comments 動作はない。字幕は動画とアクセス経路によって異なる |
| Reddit | 検索、本文、一部のコメント。一部の公開 JSON は親子 ID を含む | ブラウザによる search/read/subreddit。ログインの要否は選んだ経路による。完全なコメントツリーや全返信は保証しない。コメント投稿は提供しない |
| X/Twitter | 検索でヒットした公開の単独ポスト。一部の公式公開埋め込みは全文を返す | search/profile/tweets/thread。単独ポストが読めても返信の流れが読めるとは限らない。完全なコメントツリーは保証しない |
| 小红书（Xiaohongshu） | 公開の一覧やインデックスにノート ID、作者、タイトルがある場合がある。空のフィールドを推測で埋めてはいけない | search/read/comments。文字による説明、トップレベルのコメント、読み込み済みの返信。全コメントは保証しない。画像／動画を理解したと主張しない |
| Instagram | 一部のインデックスとプロフィールの浅い情報。HTML のアプリシェルは投稿とみなさない | search はユーザーを検索、profile はプロフィールページ、posts は指定ユーザーの投稿の説明文。統一的なコメント動作はない。画像／動画を理解したと主張しない |
| Facebook | 一部のインデックスや HTML の要約。要約は切り詰められている場合がある | search/profile。統一的な詳細やコメントの動作はない。検索の要約を全文として扱わない |
| LinkedIn | 公開求人の検索、公開 JD の閲覧 | jobs/read はまず公開 Web ページを試す。opencli を指定したときだけ直接サイト内を使う。すべての求人が読めるとは保証しない |
| BOSS（Boss直聘） | 検索インデックスに求人の要約がある場合がある | search/read で求人一覧と JD。エンコードされた給与から数字を推測してはいけない。詳細取得の代替手段はチャネルの宣言による |
| V2EX | トピック、本文、公開の返信 | hot/node/read/user。返る範囲は今回のレスポンスの内容が基準。非表示や欠落した返信は保証しない |
| 雪球（Xueqiu） | 一部の公開相場情報とインデックス情報 | quote/search/hot_posts/hot_stocks。相場の経路とコミュニティの経路はそれぞれ別に受け入れ確認する |
| Web | Agent 組み込みの検索・読み取り | Reach の web search/read は匿名の最終手段。要約、ページの外枠（シェル）、確認ページを完全な本文として扱えない |
| 小宇宙（Xiaoyuzhou） | エピソードページのタイトル、概要 | transcribe でエピソード全体を文字起こし。ユーザーが Groq Key を提供する必要がある（`agent-reach configure groq-key`） |

ログイン後の能力は「上記のブラウザ動作を有効化／試行できる」と表現し、「ログインすれば全コメントに対応」とは言わない。ユーザーがログインをスキップした場合は、取得済みの公開の証拠を渡す。
